# CardVal – בודק קלפים

אתר סטטי לגמרי (HTML/CSS/JS, בלי שרת ובלי ספריות) שבודק אם קלף אספנות מקורי.

**איך זה עובד**
1. בוחרים סוג קלף (כרגע: קלף פוקימון).
2. למעלה מוצגים שני צדי הקלף לדוגמה, והצד שצריך לצלם מודגש.
3. מצלמים את הצד הקדמי. יש אפקט "אבקת קסם" של סריקה, ואז מצלמים את הצד האחורי.
4. האתר "חושב", מנתח את התמונות ומציג ציון מקוריות, פרטים על הקלף, פירוט של כל בדיקה ובדיקות ידניות שמשפרות את הדיוק.

## הרצה
- מקומית: פשוט פותחים את `index.html` (העלאה מהגלריה עובדת תמיד).
- **מצלמה חיה דורשת HTTPS**. הכי פשוט לפרסם ב-GitHub Pages:
  Settings → Pages → Deploy from branch → בוחרים את הענף ואת `/ (root)`.
- בדיקה מקומית עם מצלמה: `python3 -m http.server` ואז `http://localhost:8000` (localhost נחשב מאובטח).

## מבנה
```
index.html            מסכים: בחירה → צילום → ניתוח → תוצאה
css/style.css         עיצוב (מותאם לנייד, RTL)
js/imaging.js         כלי עיבוד תמונה: איתור הקלף, HSV, חדות, איכות צילום
js/fx.js              אפקט הנצנצים / הסריקה
js/art.js             איורי דוגמה של שני צדי הקלף
js/cards/pokemon.js   פרופיל פוקימון: בדיקות אוטומטיות + בדיקות ידניות + מקורות
js/app.js             זרימת האפליקציה וחישוב הציון
docs/pokemon-authentication.md   סיכום המחקר שעליו מבוססות הבדיקות
```

## הוספת סוג קלף חדש
יוצרים `js/cards/<type>.js` שרושם `CardVal.cardTypes.<type>` עם `sides`, `validate`, `analyze`,
`manualChecks` ו-`sources`, מוסיפים איורים ב-`js/art.js`, ותג `<script>` ב-`index.html`.
לפני כן – אוספים את כל מה שידוע ברשת על זיהוי זיופים של אותו סוג, ומתעדים ב-`docs/`.

## מגבלות
זה ניתוח של תמונה מטלפון: הערכה, לא תעודת מקוריות. תאורה, איזון לבן, זווית ופוקוס משפיעים.
הבדיקות הפיזיות (מבחן האור, השכבה הכהה בשוליים) הן הסימן החזק ביותר, ולכן הן חלק מהתוצאה.
