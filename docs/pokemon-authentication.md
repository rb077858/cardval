# זיהוי קלפי פוקימון מזויפים – סיכום מחקר

סיכום של מדריכי זיהוי פומביים, ואיך כל סימן ממומש באתר.

| סימן | מקורי | זיוף נפוץ | איך נבדק באתר |
|---|---|---|---|
| גוון כחול בגב | כחול עמוק ואחיד: מסגרת כהה + מערבולת בהירה יותר | סגול מדי, טורקיז, דהוי או "בוצי" | גוון חציוני במסגרת (טווח 203°–228°), אחרי איזון לבן לפי הלבן של כדור הפוקה |
| רוויה | צבע עשיר | דהוי/אפרפר | רוויה חציונית ≥ 50% |
| ניגודיות בגב | שני גוונים ברורים, הדגשות לבנות | שטוח, ניגודיות נמוכה | פיזור הבהירות במערבולת + הפרש מהמסגרת |
| כדור הפוקה | קווים חדים, אדום נקי | מטושטש, אדום ורדרד/כתום | חדות (שונות לפלסיאן) + גוון האדום |
| מסגרת קדמית | צהוב-זהוב אחיד (כסוף בסדרות Scarlet & Violet מ-2023) | כתום, חיוור, קצוות מרוחים | גוון/רוויה + אחידות בין צדדים |
| מרכוז ועובי מסגרת | בערך 3 מ"מ, מרכוז סביר | חיתוך עקום מאוד, מסגרת עבה/דקה | מדידת רוחב המסגרת בכל צד |
| טקסט וסמלים | פונט נכון, חד | פונט שגוי, מטושטש, שגיאות כתיב, é חסר | חדות אזור הטקסט + בדיקה ידנית |
| מידות | 63×88 מ"מ, כ-0.3 מ"מ, כ-1.8 גרם | חריגות | יחס גובה-רוחב + בדיקה ידנית |
| מבחן האור | שכבת ליבה כהה חוסמת את רוב האור | האור עובר בקלות | בדיקה ידנית (קריטית) |
| שכבה כהה בשוליים / מבחן הקריעה | קו שחור/כחול כהה בין שתי שכבות לבנות | אין | בדיקה ידנית (קריטית) |
| דפוס הדפסה | רוזטה של הדפסת אופסט | צבע שטוח / פיקסלים דיגיטליים | בדיקה ידנית (זכוכית מגדלת) |
| ברק ומרקם | מרקם עדין | מבריק כמו פלסטיק או שעווני | השתקפות (משקל נמוך) + בדיקה ידנית |
| הולו | דפוס ספציפי לסט, רק באזורים הנכונים | קשת גנרית על כל הקלף | בדיקה ידנית |
